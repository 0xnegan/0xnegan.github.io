# 0xNegan.github.io

Personal security research blog and portfolio.

## Stack

- [Jekyll](https://jekyllrb.com/) + [Chirpy Theme](https://github.com/cotes2020/jekyll-theme-chirpy)
- Custom design system (Crimson + Amber on Charcoal)
- GitHub Pages deployment

## Deploy

```bash
# Fork chirpy-starter, clone, drop files, push
git add . && git commit -m "deploy" && git push origin main
```

Settings → Pages → Source: GitHub Actions.
